# 🍎 Daily Diet Planner (BMI & Ayurveda-Based)

---

## 📘 Project Title
**Daily Diet Planner – A BMI and Ayurveda-Based Health Suggestion Tool**

---

## 📝 Description
The **Daily Diet Planner** is a simple, web-based health application that calculates your **Body Mass Index (BMI)** using your height and weight, and then provides a **personalized diet chart** based on both **Ayurvedic principles** and your **food preference** (Vegetarian, Non-Vegetarian, or Mixed).

It helps users understand their current BMI category — **Underweight**, **Normal**, **Overweight**, or **Obese** — and recommends an ideal daily food routine for a healthier lifestyle.

This project is built entirely using **HTML, CSS, and JavaScript**, designed with a **traditional Indian theme** inspired by Ayurveda and wellness aesthetics.
